# Project Instructions

The `skillui` folder contains the official design system for this project.

Before making any UI changes, always read:

- skillui/SKILL.md
- skillui/DESIGN.md
- skillui/tokens/*
- skillui/screens/*
- skillui/screenshots/*

Requirements:

- Use only the colors from the design system.
- Use the extracted fonts.
- Follow the spacing and sizing tokens.
- Follow the same border radius and shadow styles.
- Match the visual hierarchy of the reference UI.
- Do not invent new UI styles unless requested.
- Create reusable theme constants instead of hardcoding values.

When building any UI, always read SKILL.md first and match colors, fonts, spacing, and motion exactly.
